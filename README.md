# Engineering portfolio

This static portfolio uses HTML, CSS, and vanilla JavaScript. It has no installation or build step.

## Make it yours

1. Replace `dist/assets/portrait.jpg` with your photo. Update its alternative text and remove the sample portrait caption in `dist/index.html`.
2. In `dist/index.html`, update the page title, description, name, role, introduction, and footer. Remove the template preview label.
3. Replace the example work, skills, projects, and education with your own. If you rename a project ID, update its overview link to match. Replace the sample project photos with images you have permission to publish.
4. Replace the contact placeholder with your preferred public contact details. For an email link, use an anchor with a `mailto:` URL.

Open `dist/index.html` locally to preview. Adjust the colors and layout in `dist/styles.css`.

## Deploy to GitHub Pages

1. Extract the ZIP. Commit and push its contents, including the hidden `.github` directory, to the root of a GitHub repository on the `main` branch.
2. On GitHub, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
3. In **Actions**, run **Deploy portfolio to GitHub Pages**. Subsequent pushes to `main` deploy automatically.
4. Open the Pages URL shown in **Settings → Pages** and confirm **Enforce HTTPS** is enabled there.

Example photos are from Unsplash.
